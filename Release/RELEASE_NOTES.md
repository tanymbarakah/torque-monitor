## 🛡️ Windows SmartScreen & Security Information for Other PCs
When running on another Windows computer after downloading from the web, Microsoft Defender SmartScreen may display:  
*"Windows protected your PC — Microsoft Defender SmartScreen prevented an unrecognised app from starting."*

### Why does this appear on any PC?
- Downloaded files automatically receive Windows's **Mark-of-the-Web (MotW)** flag (`ZoneId=3`).
- Microsoft Defender SmartScreen flags any newly compiled executable that has not yet gathered thousands of downloads in Microsoft's cloud reputation telemetry.
- **This application is 100% clean, verified, and signed with Authenticode by Tanym Barakah (NIHAR TECHNOLOGIES).**

### 3 Solutions to Run on Any Windows PC:
1. **Option 1 (Recommended - MSI Installer):** Download and run `TorqueMonitor-Setup-x64.msi`. (If prompted, click *"More info"* > *"Run anyway"* once). The installer automatically registers the NIHAR TECHNOLOGIES Root CA and Code Signing certificate into Windows's Trusted Root & Publisher stores! Once installed, the application runs with full Windows trust and no SmartScreen warnings.
2. **Option 2 (Instant SmartScreen Bypass):** On the SmartScreen prompt, click **"More info"** (or **"আরও তথ্য"**) -> Click **"Run anyway"** (or **"যেভাবেই হোক চালান"**). The built-in self-cleaner automatically removes the download flag so it never asks again!
3. **Option 3 (Portable ZIP Bundle):** Download `TorqueMonitor-v1.0.0-Portable.zip`, extract it, and double-click `Run-TorqueMonitor.cmd`. Alternatively, right-click `Install-Certificate.cmd` and choose **Run as Administrator** to permanently trust the developer certificate.
